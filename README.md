Сайт, предназначенный для автоматизации процессов бронирования, аренды ТС, система оплаты. Система, позволяющая клиентам быстро и удобно находить нужный и доступный автомобиль, просматривать историю поездок (если ранее был использован сервис), система лояльности для всех пользователей (услуга пригласи друга, начисление баллов за каждую поездку чтобы в дальнейшем воспользоваться скидкой)
